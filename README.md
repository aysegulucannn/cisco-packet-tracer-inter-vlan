# Cisco Packet Tracer - Inter-VLAN Routing

Bu projede Cisco Packet Tracer üzerinde iki farklı VLAN arasında iletişimi sağlayan Router-on-a-Stick yapısını kurdum.

## Kullanılan Cihazlar ve IP Adresleri

- Switch: Cisco 2960
- Router: Cisco 2911

| Cihaz / VLAN | IP Adresi | Gateway |
| :--- | :--- | :--- |
| PC0 (VLAN 10) | 192.168.10.10 | 192.168.10.1 |
| PC1 (VLAN 20) | 192.168.20.10 | 192.168.20.1 |

---

## Sonuç
PC0 üzerinden PC1'e atılan ping testi başarıyla tamamlanmış ve VLAN'lar arası iletişim sağlanmıştır.
